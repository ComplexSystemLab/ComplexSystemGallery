# 产品用户手册 — ComplexSystemGallery

> 更新日期：2026-05-18

## 1. 这是什么？

ComplexSystemGallery 是一个“项目画廊”工作台，用来把 **ComplexSystemLab** 仓库中的 Projects 目录以“项目树”的方式展示出来，并提供中间概览视口和右侧 demo 预览。

你可以把它理解为：

- 左侧：项目目录树
- 中间：项目概览视口
- 右侧：项目说明与 Demo iframe

## 2. 你能做什么

- 浏览项目树，快速定位一个项目。
- 点击项目节点后，当前地址会同步为固定链接。
- 对于已接入的项目：直接看到演示或交互内容。
- 对于未手工注册但目录内有 HTML 入口的项目：会自动接入预览。
- 对于既未注册、也没有可预览 HTML 入口的项目：会看到“待接入”提示。

## 3. 基本使用

### 3.1 打开站点

- 开发模式：维护者执行 `pnpm dev` 后，在 `http://127.0.0.1:4173/` 访问。
- 生产模式：维护者执行 `pnpm build` 后使用 `pnpm preview` 预览，或部署 `dist/`。

> 说明：首次打开时，项目树数据来自 `public/projects-tree.json`。

### 3.2 浏览项目树

- 点击文件夹节点：展开/折叠。
- 点击项目（叶子节点）：进入该项目。

一般来说，项目树中的一个“项目”对应 Lab 的一个目录，且该目录下存在 `project.txt` 文件。
当一个目录同时存在 `project.txt` 且还包含可识别的子项目（如子目录内有 HTML 入口）时，Gallery 会把它作为目录节点继续展开，避免“过早截断”。

### 3.3 查看项目页

选择项目后，工作台会同步更新：

- 顶部标题和固定链接
- 中间概览卡片与项目状态
- 右侧说明、标签和 live demo iframe

如果你点击后看到“未实现/未展示”等提示，表示：

- 该项目在 Lab 中存在并被扫描到了
- 但 Gallery 里既没有注册 `demoUrl`，也没有自动检测到 HTML 入口

这时需要联系维护者/开发者进行接入（见《开发者手册》中的“项目注册/项目页渲染”部分）。

## 4. 常见问题（FAQ）

### Q1：为什么项目树为空或很少？

可能原因：

- Gallery 没扫描到 Lab 的 Projects 目录（路径不符合默认假设）。
- Lab Projects 里的目录没有 `project.txt`，所以不会被识别为“叶子项目”。

解决方式（给维护者）：

- 检查 Lab 与 Gallery 是否同级目录。
- 执行 `pnpm gen:tree` 并查看控制台输出。
- 按需修改 `scripts/build-project-tree.mjs` 的扫描路径。

### Q2：为什么点击项目后只出现提示，没有演示内容？

原因通常有两类：

- 项目还没在 Gallery 内注册渲染入口。
- 项目目录中没有可直接作为 iframe 入口的 HTML 文件。

处理方式（给维护者）：

- 在 `src/projects/*` 中为该项目增加对应 entry
- 在 `src/projects/projectRegistry.ts` 中注册该项目路径
- 或在项目目录中补充可作为入口的 HTML（例如 `index.html` / `index_*.html`），让系统自动接入预览。

### 3.4 使用固定链接

当你在左侧目录树选中一个项目时，地址栏会变成：

- `/project?path=...`

你可以直接复制这个地址，下次打开时会自动定位到同一个项目。

### Q4：为什么 demo iframe 里提示 p5 加载失败？

原因：维护者还没有同步本地 p5 资源。

处理方式（给维护者）：

- 执行 `pnpm install`
- 执行 `pnpm sync:demo-vendor`
- 重启 `pnpm dev`

### Q3：我在 Lab 里新增了项目目录，为什么 Gallery 里看不到？

原因：项目树数据需要重新生成。

处理方式：

- 重新执行 `pnpm gen:tree`，或重启 `pnpm dev`。

## 5. 反馈与建议

- 如果你希望某个项目在 Gallery 中有更完整的展示（例如：截图、说明、交互 Demo、参数面板），把需求记录到 `docs/PRD.md` 或在开发日志中创建一条任务记录。
